# StatCan Table/Chart Validator (TVC)

A Streamlit application for validating Statistics Canada table and chart formatting rules. Deterministic-only: offline rule engine + deterministic remediation. No LLM dependency.

## Structure

- `core/` — 9 domain modules (excel inspector, rule engine, project store, report gen, etc.)
- `app/` — 3 Streamlit UI modules
- `tests/` — 17 test files, 139 tests, run in ~4s
- `config/rule_packs/` — YAML-defined validation rule packs
- `config/symbols/` — StatCan-specific symbol definitions (suppression, confidentiality)
- `tests/fixtures/` — 14 StatCan fixture workbooks (10 original + 4 fresh from recent publications)

## Context Budget Rules

- **Keep file dumps under 50 lines.** Use `patch` not full file reads.
- **Use `diff` not full dump.** Prefer `git diff` or `patch` output.
- **Commit after each sub-task.** Forgejo is single source of truth.
- **Use `delegate_task` for work touching 3+ files.** Orchestrator pattern (`role="orchestrator"`) splits work into parallel leaf sub-agents, returns only summary.
- **For multi-session work:** finish a bounded unit → `/compress` → `/new`

## Testing

- `python -m pytest tests/ --tb=short -q` — 139 tests, all must pass
- Uses `conftest.py` with shared fixtures (in-memory repo, project store, rule loader)
- 14 StatCan fixture workbooks in `tests/fixtures/`
- `InMemoryRepositoryClient` replaces git dependency in tests (no real Forgejo needed)
- Dual test coverage: core logic tests + workbook fixture integration tests

## Domain Rules

- StatCan suppression/confidentiality symbols: `x`, `F`, `E`, `..`, `...`
- Rule packs are YAML files in `config/rule_packs/` — loaded at startup
- Tables and charts have separate validation rule sets (101 rules each)
- Identification and changes are fully deterministic — no LLM. Findings come
  from `core/excel_inspector.py`; resolutions come from the deterministic
  remediation catalogue (`core/remediation_catalog.py` + `remediation_applier.py`)
- Report generator produces bilingual Markdown audit reports (EN + FR)
- T101-STANDARD-SYMBOLS and C101-STANDARD-SYMBOLS only fire when empty data cells
  exist but no standard symbols are found (tables with complete data don't need symbols)
- Chart title extraction uses `p.r` (openpyxl Paragraph attribute), not `p.runs`
- Symbol detection is scoped to the data region only (not footer/note rows)
